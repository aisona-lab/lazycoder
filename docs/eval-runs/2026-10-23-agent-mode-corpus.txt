- Isolation was soft. Each subagent was told to read only its shard file
  (file, line, code; no labels, ids or PR links) and nothing else: no repo,
  no git, no web. They share the filesystem with the repo, so this rests on
  instruction-following, not on a sandbox. Each reported reading only its
  shard.
- Confound: the subagent prompt added "Only fail a rule when the code in
  front of you actually shows the problem; do not fail on style taste or
  speculation", which the packet instructions do not say. It pushes toward
  silence. This run measures that prompt as much as the reviewer.
- Scoring is by rule identity. On requests-7308-old-0 the reviewer flagged
  the header regexes (`$` also matches before a trailing newline, so
  "bar\n" passes the CR/LF check; fix: \Z or fullmatch) under R7/R12/R13.
  The label is R4, so it scores as "unlabelled", not caught. The PR is
  "Fix cosmetic header validity parsing regex"; that this is the same defect
  is likely but not verified against the fix commit.
